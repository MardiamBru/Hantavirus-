# 📋 Guia de Impressão do Folheto

## Como Imprimir o Folheto com Fidelidade ao Design Original

### ⭐ Recomendação Principal

**IMPRIMA via `flyer.html` (através do navegador)** - Isso preserva melhor os elementos visuais, cores e o layout exato do design original.

---

## 🖨️ Passo a Passo para Impressão

### Opção 1: Impressão Recomendada (via HTML)

1. **Abra o navegador** e acesse:
   - Local: Abra o arquivo `/flyer.html` no seu navegador
   - Online: Acesse [flyer.html](flyer.html) do repositório

2. **Configure a impressão:**
   ```
   Tecla: Ctrl + P (Windows/Linux) ou Cmd + P (Mac)
   ```

3. **Configurações de impressão (IMPORTANTE):**
   - **Tamanho do papel:** A4 (210 × 297 mm)
   - **Orientação:** Retrato (Portrait)
   - **Margens:** Nenhuma ou Mínima
   - **Escala:** 100% (Não redimensione)
   - **Cabeçalhos/Rodapés:** Desativado
   - **Gráficos de fundo:** ✅ ATIVADO (para manter cores)
   - **Impressão em cores:** ✅ RECOMENDADO

4. **Clique em "Imprimir"**

### Opção 2: Impressão via PDF

Você pode usar o arquivo `flyer.pdf` já pronto, mas ele foi gerado automaticamente. Para melhor qualidade, prefira a Opção 1.

## 🎨 Especificações Técnicas

### Cores Exatas
- **Vermelho:** #d92d2d (RGB: 217, 45, 45)
- **Preto:** #1b1b1b (RGB: 27, 27, 27)
- **Azul:** #3d6fb2 (RGB: 61, 111, 178)

### Dimensões
- **Tamanho:** A4 (210mm × 297mm)
- **Orientação:** Retrato
- **Margem recomendada:** 0mm (preenche toda a página)

### Fontes
- **Família:** Arial, Helvetica, Sans-serif
- **Pesos:** Regular (400), Bold (700), Extra Bold (900)

---

## ✅ Checklist de Qualidade

Após imprimir, verifique:

- ✓ Logo FATEC visível e bem definido no topo
- ✓ Cores vermelhas, pretas e azuis nítidas
- ✓ Texto legível em todos os tamanhos
- ✓ QR Code escaneável (teste com seu celular)
- ✓ Layout sem cortes ou distorções
- ✓ Ícones e símbolos claros

## 📱 Escaneando o QR Code

Após imprimir o folheto:

1. Abra a câmera do seu celular
2. Aponte para o QR Code no canto inferior direito
3. Clique no link que aparecer
4. Você será redirecionado para o site com as informações completas

---

## 💡 Dicas Extras

- **Para melhor qualidade:** Use papel A4 branco 120g ou superior
- **Impressoras recomendadas:** Laser color ou jato de tinta com qualidade alta
- **Economizar tinta:** Se for imprimir muitas cópias, considere usar tinta preta para as demais cópias (remova as cores antes de imprimir)
